# Project Overview

SmartScanner Pro is a mobile utility designed to simplify personal expense management and receipt archives.

## Core Value Proposition
"Capture. Categorize. Budget." SmartScanner Pro replaces tedious manual ledger entries with automated AI parsing. Users scan a receipt via their camera or import an invoice from the library, and the application extracts the total spent, purchase date, merchant name, and updates progress against a monthly budget limit.

## Target Audience
*   **Discretionary Spenders:** Users wanting automated expense insights without manual entry.
*   **Business Travelers:** Users compiling receipt logs for corporate expense claims.
*   **Budget-Conscious Users:** Individual users seeking visual aids to manage monthly limits.
